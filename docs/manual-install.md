# 手动安装

1. 安装并启用独立项目 Godot MCP Native：<https://github.com/yurineko73/Godot-MCP-Native>。
2. 将 `addons/godot_ai_manager/` 复制到 Godot 项目。
3. 在 **项目 > 项目设置 > 插件** 中启用 **Godot AI 管理器**。
4. 安装官方 Codex CLI 或官方 Kimi Code CLI。
5. 在 Dock 设置中保留空路径以自动查找，或填写可执行文件完整路径。
6. 保持 Godot MCP Native HTTP 地址与 Dock 设置一致，默认 `http://127.0.0.1:9080/mcp`。

本项目不提供 ZIP 安装包。
